İLİM YOLCULUĞU – WEB SİTESİ

Dosyalar:
- index.html: oyun
- manifest.webmanifest: ana ekrana ekleme bilgileri
- sw.js: çevrimdışı önbellek
- icon-192.png / icon-512.png: uygulama simgeleri
- hakkimizda.html, gizlilik.html, kaynaklar.html: bilgilendirme sayfaları

Yayınlama:
1. Bu klasördeki dosyaların tamamını GitHub deposunun kök dizinine yükleyin.
2. GitHub deposunda Settings > Pages bölümünü açın.
3. Deploy from a branch seçin; branch olarak main, klasör olarak /(root) seçip Save'e basın.
4. GitHub Pages'in verdiği HTTPS adresini kullanın.

Notlar:
- İlk geliştirme sürümünde 10 kategoride 100 soru bulunur.
- Oyun puanları cihazın tarayıcısında saklanır; hesaplar arası senkronizasyon yoktur.
- Reklam entegrasyonu henüz yapılmamıştır.
- Gizlilik metni taslaktır; reklam/analiz servisleri eklenmeden önce gerçek uygulamaya göre güncellenmelidir.
- Dini içerik, yayın öncesinde yetkin bir editör tarafından doğrulanmalıdır.
